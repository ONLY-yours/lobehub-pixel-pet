这一轮修复一个在 Windows 上很严重的问题：**用输入法打中文时，聊天框会直接消失**（英文没问题）。

原因：输入法会弹出自己的候选词窗口，这会触发窗口失焦和鼠标“移出”事件；而“鼠标离开就隐藏控件”的逻辑正好监听了这两个事件，一触发就把聊天框隐藏，输入框被隐藏又会失去焦点，正在拼写的内容被打断。

修法：1) 鼠标是否在宠物上，改由主进程读取系统光标位置来判断，不再依赖这些容易被输入法干扰的网页事件；2) 输入法拼写期间，以及最后一次按键后的 1.5 秒内，聊天框不会收起；停止输入、鼠标又不在窗口上之后才收起，草稿保留。

验证：用合成的输入法事件复现了问题——修复前的代码在这一步失败（聊天框被隐藏），修复后通过。**没有在真实的 Windows 输入法上验证**，需要你在 Windows 上用中文输入法确认。
